## 2. Lecciones técnicas (no repetir estos errores)

1. **Orden de ScrollTrigger:** crear primero los pines, en el orden del documento, y después las animaciones normales (`reveals`, `words`…). Si no, las posiciones se calculan sin el espacio de los pines y todo se dispara antes de tiempo.
2. **Nunca bajar la opacidad de elementos apilados** que se solapan (se mezclan las letras). Usar escala u overlay opaco.
3. **Restauración de scroll:** el navegador/Astro restauran el scroll antes de que GSAP arme los pines. Por eso `nav.ts` guarda la posición y `motion.ts` la restaura **después** del `refresh`, llamando antes a `lenis.resize()` (si no, Lenis recorta a su límite viejo). En recarga se empieza arriba.
4. **En un "atrás" con `ClientRouter`, `location` ya es el destino** cuando salta `astro:before-preparation`; la página que se deja es `event.from`.
5. **GSAP pisa `transform` de CSS:** para centrar o hacer hover en elementos animados por GSAP, usar la propiedad `translate`/`scale` individual en CSS, no `transform`.
6. **`String.replace` en JS interpreta `$$` como `$`** (rompió un selector `$$`). Para ediciones con `$` usar la herramienta Edit, no scripts con `replace`.
7. **`$` vs `$$` en `motion.ts`:** `$` devuelve un elemento (o null), `$$` una lista.
8. Solo animar `transform`, `opacity` y `clip-path` (excepción consciente: el marquee y los puntos que laten usan transform/opacity también).
9. **Probar en celular:** la ventana del navegador de pruebas no se redimensiona; se simula con un `<iframe style="width:390px">` (los media queries leen el ancho del iframe). Comprobar que `scrollWidth === clientWidth`.
10. **Scripts con `node -e '...'` en bash:** las comillas simples del código (p. ej. `['antes']`) cierran la comilla de bash y se pierden. Para archivos con comillas, `$` o plantillas usar Write/Edit o un script escrito a archivo.
11. **Mosaico con huecos:** con `grid-auto-flow: dense` y tamaños por posición queda una última fila coja. Solución: construir el mosaico por **bloques que cuadran** (4×2) según la cantidad de fotos.
12. **Carruseles:** un contenedor con `overflow-x: auto` + scroll-snap solo se desliza con dedo/rueda; con mouse no se puede arrastrar. Para "deslizar" en escritorio hay que implementar arrastre con pointer events (y `touch-action: pan-y`). Un `<dialog>` modal no anima solo: animar la entrada con `@keyframes` en `[open]` y la salida con una clase `is-closing` antes de llamar a `close()` (e interceptar `cancel` para Esc).
13. Astro 7 exige Node ≥ 22.23.4; con `nvm use` en Windows la terminal ya abierta puede no tomar el cambio.
14. **Isla de React + SSR:** leer `location`/`sessionStorage` solo dentro de `useEffect` (tras montar) para no romper la hidratación; las variables `PUBLIC_*` se leen con `import.meta.env` también en el cliente.
15. **`window.open` para WhatsApp** debe llamarse dentro del clic (síncrono) o el navegador lo bloquea; el `POST /quotes` va aparte (fire-and-forget) y nunca debe impedir abrir WhatsApp.
16. **Pruebas con el navegador automatizado:** la herramienta bloquea imprimir URLs con query string (devuelve `[BLOCKED]`); no devolver `location.search`. Crear/borrar `.env` reinicia Vite y recarga la página (corta una prueba en curso).
18. **El anillo de foco se recorta con `overflow`:** cualquier ancestro con `overflow` ≠ `visible` (incluido `overflow-x:auto`, que fuerza también el vertical) corta el `outline`/`box-shadow` que sobresale. Reglas: (a) no poner `overflow:hidden` en contenedores de controles (el `fieldset` solo necesita `min-width:0`); (b) en scrollers, dar `padding` ≥ 8px y compensar con margen negativo; (c) animaciones de altura (`Collapse`) solo recortan mientras animan y terminan en `overflow: visible`; (d) en elementos pegados al borde, anillo hacia adentro (`outline-offset` negativo). Causa original: `.q-block { overflow:hidden }` del cotizador.
19. **Columnas de `1fr` con titulares largos:** `1fr` = `minmax(auto, 1fr)`, así que una palabra larga y grande ensancha su columna y aplasta a la otra. Usar `minmax(0, …fr)` y ajustar el tamaño del titular.
20. **TypeORM + tsx/esbuild:** esbuild no emite `emitDecoratorMetadata`, así que **cada `@Column` necesita `type` explícito** y las relaciones usan thunks (`() => Entidad`) con `Relation<>` para evitar ciclos. TypeORM carga entidades/migraciones por patrón de archivos con un `require` nativo de Node, que **no entiende .ts dentro de Vitest**: por eso las entidades van en una lista explícita (`database/entities.ts`, con prueba-guardia) y en Vitest las migraciones no se cargan (`process.env.VITEST`); las pruebas crean la base con el CLI en otro proceso.
21. **Express 5:** `req.query` es de solo lectura (lo validado va a `res.locals.validated`) y los errores async llegan solos al manejador de errores. **Zod 4:** `z.config(z.locales.es())` para mensajes en español.
22. **PostgreSQL temporal en Windows para pruebas:** `initdb` + `pg_ctl` de la instalación (`C:\Program Files\PostgreSQL\16\bin`) en otro puerto, con `--auth=trust`; `pg_ctl start -w` deja colgado el comando del shell (el servidor ya está arriba: comprobar con `psql` y seguir). Borrar el directorio al terminar.
23. **Versiones:** TypeScript 7 (recién salido) y `@types/node` de otra versión mayor dan problemas; se fijó TypeScript 5.x y `@types/node@22`. Vitest necesita la config como `.mts` en un proyecto CommonJS.
24. **Ejecutor de comandos:** al invocar `scripts/run.js` fuera de `npm run`, `tsx`/`vitest` no están en el PATH → el ejecutor antepone `node_modules/.bin`. No definir alias cortos de flags (`-e`) en un wrapper: se comen los de la herramienta envuelta. En Windows, `node` no entiende rutas `/c/...` de Git Bash (usar `C:/...`).
25. **Schema de PostgreSQL con TypeORM:** la opción `schema` NO crea el schema ni afecta al SQL crudo de las migraciones; sin schema previo falla con `get_namespace_oid`. Hacen falta `createSchema` antes de migrar y el `search_path` en la conexión (`extra.options = '-c search_path=…'`). `migration:generate` escribe `"public".` en los enums: hay que quitarlo a mano si se quiere una migración agnóstica al schema.
26. **Subidas firmadas a Cloudinary:** la firma es SHA-1 de los parámetros ordenados (`k=v&k=v`) + el API secret; los parámetros firmados deben enviarse idénticos. `max_file_size` no es firmable en la subida (solo con un upload preset), por eso el tope de 10 MB y el redimensionado se aplican en el navegador. HEIC no lo decodifica Chrome: se sube el original si pesa ≤ 10 MB.
27. **No usar `npx tsc` fuera de `api/`:** en `web/` no hay TypeScript instalado y npx descarga un paquete homónimo (un aviso, no el compilador). Validar la web con `npm run build`.
28. **Regex en scripts bash/node:** las barras invertidas se pierden con comillas dobles (`\/`, `\-`). Editar con la herramienta de edición, no con `node -e` entre comillas. `[A-Za-z0-9_-/]` es un rango inválido: el guion va al final.
29. **Lenis y listas con scroll propio:** todo elemento con `overflow: auto` dentro de la página (dropdowns, paneles, diálogos) necesita `data-lenis-prevent`; si no, Lenis se queda con la rueda del mouse y la página se mueve en lugar de la lista (en táctil no pasa). Ya lo llevan el menú, la presentación, el `Combobox` y el resumen móvil del cotizador. Todo componente nuevo con scroll interno debe llevarlo.
30. **Motion: `initial={false}` con fotogramas (keyframes):** el elemento arranca en el ÚLTIMO fotograma y NO anima al montarse; si ese fotograma es invisible (opacidad 0, como en un bucle que se desvanece al final), la animación nunca se ve. Dar `initial` explícito con el primer fotograma. Se detectó midiendo `getComputedStyle().opacity` cada 250 ms: mirar capturas sueltas engaña porque se pierde el momento del ciclo.
31. **Datos de referencia y migraciones:** al revertir una migración que crea el catálogo se borra TODO el catálogo (también lo sembrado por `seed:catalog`); al volver a subir, la migración solo trae lo mínimo para mover datos. Por eso `migrate.js` corre el seed del catálogo al final: el catálogo completo vive en `catalog.data.ts`, no en la migración.
32. **Los `Write` pueden fallar si el archivo cambió:** después de editar un archivo con scripts hay que volver a leerlo antes de reescribirlo con la herramienta de escritura. Los heredocs largos en bash siguen fallando con comillas: usar la herramienta de escritura.
33. **Cambios de enum en PostgreSQL con TypeORM:** quitar un valor de un enum (`pregunta_tipo`) genera renombrar el tipo, crear el nuevo y convertir la columna con `USING`; falla si quedan filas con el valor retirado, por eso la migración borra antes lo que ya no cabe. El `down` de una columna `NOT NULL` recién agregada debe añadirla nullable, rellenarla y recién entonces marcarla `NOT NULL`.
34. **Borradores guardados en el navegador:** al cambiar la forma de lo que guarda `sessionStorage` hay que subir la versión de la clave (aquí `seima:quote:v2`) y hacer que el código tolere formatos viejos, o un visitante con un borrador anterior rompe el formulario.
17. **Heredocs en bash** con comillas/`$`/plantillas fallan a veces: para archivos de código usar la herramienta Write.
